# 3DX World Editor - downloads

**By KingColossus.** Edits 3DXChat `.world` files in 3D with the game's real models, without the in-game editor's lag.

- **Download:** [latest release](https://github.com/Deaeath/3dx-world-editor-releases/releases/latest) - `3DXWorldEditor.exe`, checked against `SHA256SUMS.txt`
- **Use it online, no install:** https://deaeath.github.io/3dx-world-editor/
- **Bug reports and ideas:** https://github.com/Deaeath/3dx-world-editor-feedback/issues

With [3DXModKit](https://github.com/Deaeath/3DXModKit), use **Install / Update** on the control panel's Mods tab. It downloads the newest release from here, checks its SHA-256 and asks before installing.
